# XiaoBai

Expo React Native scaffold for the XiaoBai AI travel companion UI.

## Run

1. Install dependencies with `npm install`.
2. Start the app with `npm run start`.
3. Use `npm run ios`, `npm run android`, or `npm run web` from the Expo menu.

The current screen uses inline placeholders for the heavier illustration assets, so the project stays lightweight until you are ready to swap in real artwork.
